## 🏆 Principal projeto

### 🏥 PROMPTUARIO

Sistema de informação em saúde que estou desenvolvendo academicamente, com evolução de uma arquitetura monolítica para uma arquitetura baseada em **microsserviços**.

O projeto envolve:

* Frontend com **React + TypeScript**
* Backend com **Python + FastAPI**
* **PostgreSQL**
* **RabbitMQ**
* **Docker / Docker Compose**
* **API Gateway**
* Autenticação com **JWT**
* Controle de acesso baseado em **RBAC**
* Comunicação assíncrona
* Arquitetura distribuída
* Observabilidade
* Integração com serviços de IA
* Estruturação para escalabilidade e evolução independente dos serviços
